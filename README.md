# 台場スパイゲーム

ショッピングモールを歩き回って遊ぶ、16人・3チームのスパイゲームです。お題の写真を撮って手掛かりを集め、「答えの写真」が撮られた場所を推理します。チームには、答えを知っている内通者が紛れています。

- 遊ぶ：https://odaiba-spy.onokorocreation.com/ （「1人でデモを遊ぶ」で、ほかの15人とGMをコンピューターが動かします）
- 2026年10月4日に、お台場で16人で遊んだときの記録：https://odaiba-spy.onokorocreation.com/archive/

## できること

**参加者の個人ページ**（`/p/<鍵>`）

- GMが参加者ごとに推測できないURLを発行し、本人に送ります。ログインもパスワードも要りません。
- チームと役職の確認。役職はタップしたときだけ表示し、開く前は色でも分からないようにしています。
- 出ているお題の写真を撮って投稿。GMが認めると、出した人にだけ手掛かりか割符が届きます。
- 役職だけの情報：内通者には答えの写真と張り込みの任務、密使には本物の3項目、内通者・密使・蜃気楼にはGMとの接触の時間・場所・合言葉。
- 妨害の発動、緊急任務、確保写真（チームで1回）、投票、結果。

**GM手帳**（`/gm/<鍵>`）

- 判定待ちの写真を「獲得／却下」の1タップでさばく。却下の理由もワンタップで送れる。
- 同じお題の早い者勝ちは、GMが判定した順ではなく**投稿した時刻の順**。先に投稿された写真が残っているうちは、後の写真を認められないようにしている。
- 接触：会えた人の名前を押すと、伝える内容（チームの公安の名前、内通者の名前、妨害の権利）が本人のページに自動で届く。
- 確保写真の採点は、答えの20項目にチェックを入れるだけ。点数はすべて自動計算。
- チームと役職は3ターム分を自動で割り振り（同じ人が同じ特殊役職を続けて引きにくいように）、始まる前なら手で直せる。

## しくみ

- Cloudflare Pages（静的ファイル）＋ Pages Functions（API）＋ D1（SQLite のデータベース）。ビルドの手順はなく、画面は素の HTML / CSS / JavaScript。費用は0円。
- 画面は数秒ごとに状態を確かめに行く。ゲームの状態が変わるたびに `ver` を1つ増やし、変わっていなければ中身を返さないので、16人で数時間遊んでもデータベースの読み出しはわずか。画面が隠れているあいだは止まる。
- 画面の更新は、変わったところだけを書き換える（自動の更新と同時にボタンを押しても、空振りしない）。
- 写真は送る前にスマホの中で縮める（位置情報などもここで消える）。写真は同じチームの人とGMにだけ見え、結果発表のあとは全員に見える。
- 答えの写真は `public/_secret/` に置き、直接は開けない（`functions/_secret/` が404を返す）。APIが、そのタームの内通者とGMにだけ渡す。

```
public/            画面（トップ、個人ページ、GM手帳、記録）
  play.js          個人ページ
  gm.js            GM手帳
  common.js        共通の道具（通信、写真の縮小、画面の書き換え）
  archive/         2026年10月4日の記録（静的サイト）
functions/api/     API の入口
src/
  engine.js        ゲームの進行と、画面に返す状態
  scoring.js       得点の計算
  roles.js         チーム分けと役職の割り振り
  bots.js          デモ用のコンピューターの参加者とGM
  content.json     お題・手掛かり・割符・接触の場所（scripts/build_content.py で作る）
  schema.sql       データベースの表
test/
  scoring.test.mjs 当日の投票と確保点から、46人分の点数が記録と一致するか
  flow.mjs         1ターム分を最初から最後まで通す（41項目）
  demo.mjs         デモのコンピューターが動くか
```

## 手元で動かす

```
npm install
npm run db:local          # 手元のデータベースに表を作る
npm run dev               # http://localhost:8790
npm test                  # 得点の計算のテスト
node test/flow.mjs        # npm run dev を動かしたまま、別の画面で
```

本番のゲームを作る `/new` には主催者の鍵が要ります。手元では `.dev.vars` に `ADMIN_KEY=...` と書きます。

## 公開

```
npx wrangler d1 execute odaiba-spy --remote --file src/schema.sql   # 初回だけ
npx wrangler pages deploy public --project-name odaiba-spy --branch main
```

## 記録について

参加者の名前はすべてコードネームに置き換えています。答えの写真に写り込んだ一般の方はぼかしています。お題や手掛かりは2026年10月時点のお店に合わせて作ったもので、今は変わっている場合があります。
