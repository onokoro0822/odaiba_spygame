# 台場スパイゲーム 2026.10.04 アーカイブ

2026年10月4日に、お台場の3つのモール（ダイバーシティ東京プラザ・アクアシティお台場・デックス東京ビーチ）で遊んだ、オリジナルのスパイゲームの記録サイトです。

- 概要：日程、役職、総合順位
- ルール：当日のルールの要約
- お題：各ターム20個、全60個の指令と条件
- 答え：当日と同じ順番で手掛かりを開きながら推理できる。答えの写真と20個のチェック項目
- 結果：総合順位、タームごとの確保点・正体・投票
- GM手帳：当日の進行と、送った文面

参加者の名前はすべてコードネームに置き換えています。答えの写真に写り込んだ一般の方はぼかしています。

## 構成

ビルド不要の静的サイトです。

- `index.html` / `style.css` / `app.js`：画面
- `data.json`：お題・手掛かり・結果などのデータ
- `img/`：答えの写真

ローカルで見るとき（`data.json` を読み込むため、サーバー経由で開く）:

    python3 -m http.server 8000
    # http://localhost:8000 を開く
